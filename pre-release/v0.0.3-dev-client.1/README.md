# IPA Board client artifacts: v0.0.3-dev-client.1

Engine `v0.0.3-dev`; dictionary `v0.0.1-dev-lexicon`. These standalone files are extracted from the same packaged AAR. classes.jar was converted by the installed Android SDK D8 36.1.0, min API 26. DEX and JNI must be installed together.

`lexicon.ipad` is an unwrapped, developer-compiled IPADWG01 v2 24-bit dictionary. `client.json` describes this immutable batch; the client discovers updates exclusively through the repository root `board-update.json`. This batch is advertised only after its complete public Git commit has been pushed. See [integration documentation](../../README.md).

`build.json` records matching AAR/class/JNI provenance. `SHA256SUMS` covers every other batch file. Preserve the dictionary manifest and source notices. No new phone tests or performance measurements are claimed by this conversion.
